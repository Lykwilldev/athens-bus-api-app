# athens-bus-api-app
A simple React.js app built using Typescript made to replicate OASA Telematics, the official app provided by the Athens Urban Transport Organisation for educational purposes.


Provides a simple UI allowing users to select a bus and a route, see it's stops and all the bus arrivals of that stop

For now, usable only by installing the code as well as axios and running it on localhost

Known Bugs:
- Selecting a bus stop and then selecting another line doesn't clear that stop

--------------------------------------------------------------------------------------------------------------------------------

Μια απλή διαδυκτιακή εφαρμογή δημιουργημένη με χρήση React.js και Typescript με σκοπό να αντιγράψει την ΟΑΣΑ Τηλεματική εφαρμογή της ΣΤΑΣΥ για επκαιδευτικούς σκοπούς. 

Προσφέρει ενα απλό UI που επιτρέπει στους χρήστες να διαλέξουν μια διαδρομή λεωφορίου, να δούν ολες τις στάσεις της καθώς και όλες τις αφίξεις λεωφορείων της επιλεγμένης στάσης.

Προς το παρόν χρησιμοποιείται μόνο τοπικά, εγκαταστίθοντας τον κώδικα και το axios και τρέχοντάς το μέσω localhost

Γνωστά bugs:
- Με την επιλογή μιας στάσης και έπειτα την επιλογή άλλης γραμμής λεωφορείου, η επιλεγμένη στάση δεν εκκαθαρίζεται
